# Security Policy

If you discover a security vulnerability, please report it privately using GitHub Security Advisories. Do not create a public GitHub issue or discussion post, as this could put the security of other users at risk.

## How to report

1. Go to the [Security Advisories page](https://github.com/fosrl/pangolin/security/advisories/new) for this repository, or open the "Security" tab and select "Report a vulnerability".
2. Describe the vulnerability and include:

- Description and location of the vulnerability.
- Potential impact of the vulnerability.
- Steps to reproduce the vulnerability.
- Potential solutions to fix the vulnerability.
- Your name/handle and a link for recognition (optional).

We aim to address the issue as soon as possible.
